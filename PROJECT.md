# Driftwood

A short low-poly 3D raft game that runs in the browser. Drift across the ocean, hook floating planks, grow your raft, and survive the shark until you reach the island.

## Stack
- Three.js (3D)
- Vite (dev server and build)
- Plain JavaScript, no framework

## Run locally
1. npm install
2. npm run dev

## Controls
- Click the water: throw the hook
- B: toggle build mode, click next to the raft to add a tile (3 planks)

## Versions

- V2 Island update: land on the island, explore, build ()
